# 代码生成·项目图表

本 Skill 指导 Agent 基于**当前项目/代码仓库**生成 Draw.io 格式图表，支持四种类型：技术栈图、系统架构图、数据结构图、E-R 图。

## Step 0：任务识别


| 用户表述 / 关键词         | 执行                            |
| ------------------ | ----------------------------- |
| 技术栈、整体技术栈、组件选型     | `reference/tech-stack.md`     |
| 系统架构、分层结构、调用流程     | `reference/system-arch.md`    |
| 数据结构图、表结构图、实体字段关系图 | `reference/data-structure.md` |
| E-R 图、实体关系图、数据库关系图 | `reference/er-diagram.md`     |


## 使用时机

- 用户需要根据当前项目画技术栈图、系统架构图、数据结构图或 E-R 图
- 用户提到「根据当前项目」「根据代码」「画我们系统的……」

模型结构、注意力、训练数据流不要用本 Skill，走 `drawio-diagram` 的 `tech-diagram.md`。

## 通用规范（四种图表共用）

### 只画代码里有的东西

节点、依赖、协议、表、字段和基数都要能指到文件（依赖清单、入口、DDL、ORM）。仓库里没有的不要编。看不清的标「待确认」。传递依赖不要整棵树画上去，只保留直接依赖里的框架和运行时。

### Draw.io 基础

- 使用 **mxGraphModel**，画布背景 `#FFFFFF`，`grid="0"`
- 仅使用 Draw.io 内置形状，输出未压缩 XML
- 节点 `vertex="1"`，连线 `edge="1"`，除根节点外 `parent="1"`
- `id` 唯一。手写时 `& < >` 转义恰好一次
- 节点标签简洁，符合技术文档表达习惯

### 色彩与字体

下面的蓝/橙只在某个 reference **没有**指定颜色时使用。技术栈、架构、数据结构、E-R 四份 reference 都规定了黑白学术配色，生成时以那份 reference 为准，不要改成蓝橙。

| 用途 | 颜色值 |
|------|--------|
| 主色调 | #3366CC |
| 副色调 | #7FBFFF |
| 强调色 | #FF9966 |
| 深色背景字体 | #FFFFFF |
| 浅色背景字体 | #333333 |
| 画布背景 | #FFFFFF |

- 字体：Helvetica，字号 12–13。图题 13–14，斜体放在图下方
- 连接线：`endArrow=blockThin` 或 `classic`，`strokeColor=#333333`

### 输出要求

1. 图表总览（图里有哪些块，各自对应哪些文件）
2. 完整 mxGraph XML
3. 导入说明：diagrams.net 中打开或拖入
4. 图题与一句可粘贴的论文引用。没有依据的项单独列为「待确认」
